# 开发进度

最后更新：2026-08-18（Asia/Shanghai）

## 当前产品状态

- 产品名、图标、设计、README、隐私和启动方式已统一为首个正式版本“声作 1.0.0”。
- 左侧“更多功能”已取消折叠，字幕配音、多人对话和本地引擎始终显示。
- 全局界面已内置并优先使用华为官方未修改的 HarmonyOS Sans SC 字体；字体随软件携带，不依赖系统安装，设置页与第三方许可目录保留显著声明和完整许可文本。
- 本地引擎卡片已精简为用途、电脑要求、空间和语言四项；19 种方言改为按需查看，推荐星级继续保留。
- 单段配音统一使用 2,000 个有效字的安全上限，空格和空行不计数；超出时会提示并禁止提交。
- 单段长稿不再整段交给模型：超过 160 个有效字会按标点拆成安全短段，逐段缓存和生成，校验全文没有漏字后再合并为一个 MP3；失败重试只续做未完成短段。
- VoxCPM2 长稿使用更严格的约 70 个有效字分段，Worker 再优先按完整句子生成；后续片段比首段明显变快时自动重做一次，仍偏快则使用无变调节奏校正，避免长稿越读越快。其他模型继续使用 160 字安全分段。
- 三个创作页新增“自然口播 / 稳健长稿 / 情绪演绎”生成方式；稳健模式会进一步缩短安全分段。每个新片段生成后都会检查时长、音量、静音、削波和相邻语速漂移，异常时自动重做，持续异常则停止该段并保留此前缓存，避免把明显漏读或乱速音频直接合并。
- 新增项目级发音词典，可把人名、品牌名和英文缩写按最长原文优先替换为指定读音；只改变送入模型的朗读文本，不改项目原稿，单段、字幕和多人对话共用。
- 新增可选“智能文稿”：支持 OpenAI 兼容接口，可对选中文字或全文执行自然口语、整理停顿、精简文稿、检查发音、翻译和自定义处理；入口在鼠标悬停或键盘聚焦时会先解释用途，每个选项会明确说明具体会改什么，结果页显示本次处理方式、具体变化和前后字数，再并排对比，确认后才替换，并可一键撤销。发音建议可加入项目词典，表达和情绪建议会按当前模型真实能力过滤。
- 设置中的入口严格命名为“API配置”，只保留 Base URL、Model 和 API Key，保存后直接可用，新 Key 覆盖旧 Key；API Key 输入框会明确提示“已保存；如需更换，请输入新的 API Key”。密钥由 Electron Main 使用 Windows 安全存储加密，Renderer 不能读取密钥。未配置时不影响任何本地配音功能；只有主动使用“智能处理”或“智能整理脚本”时才发送对应文字，不发送录音、生成音频或本地路径。
- 所有需要文本 API 的入口统一使用闪光图标；未完成 API配置时按钮置灰且不可点击，悬停或键盘聚焦会直接说明需要到设置中配置。创建声音等纯本地操作已换用普通功能图标，避免混淆。
- 已删除独立“使用帮助”页面、侧栏入口和设置中的重复帮助项，常用操作直接在对应页面表达，不保留闲置说明页面。
- 已完成一轮全界面文案审查：设置、模型下载、声音克隆、任务恢复、生成进度和常见报错只说明“现在发生了什么、下一步怎么做”，不再向用户展示断点、缓存、脱敏、安装收据、Worker 或环回端口等内部术语；新增自动测试防止这些谜语话重新出现在界面。
- 发音词典改为挂载到窗口根节点的宽版居中弹窗，不再被创作页动画容器裁切；规则多时只滚动弹窗内容，保存和取消始终可见。
- 单段长稿合并改为按句号、逗号和省略号使用不同停顿，继续保留片段边缘淡化，减少机械等距停顿。
- VoxCPM2 节奏稳定器已在 RTX 4070 上用 5 段中文长稿真实生成验证，得到 28.24 秒 MP3；本次各段均处于稳定范围，无需触发重试或拉伸。
- 三个创作页都提供“试听 30 字”：只截取开头 30 个有效字符，明确显示试听原文；单段创作还会在正文框中直接选中试听范围。试听结果不保存到生成记录，也不提供导出。
- 单段、字幕和对话页按模型真实能力显示控制项：VoxCPM2 提供自由表达要求，CosyVoice 仅在方言模式提供表达要求，IndexTTS-2.5 提供情绪档位与自由表达；切换模型或语言会自动隐藏不支持的选项，Main 端也会再次清理无效参数。
- “表达要求”统一改为常用预设下拉，提供自然清晰、轻松亲切、沉稳专业、温暖柔和、活泼有感染力和舒缓克制；选择“自定义”后才显示输入框。三个创作页共用同一控件，仍按当前模型与语言能力决定是否显示。
- 多人对话保留本机“角色名：台词”直接识别，并新增可选的 API 智能整理：可从小说、分镜稿或混杂脚本中去除场景、镜头、动作、音效和普通叙事，提取角色及真正说出口的台词；结果先预览再替换，详细提示词保存在 `prompts/多人对话脚本整理.md`。角色名可自定义且不限制四个角色；项目统一使用一个模型和语言，每个角色可单独设置声音、模型支持的情绪与语速，角色名不再误传为模型表达提示词。
- 克隆声音弹窗可在创建前直接播放刚选择或拖入的样音，避免选错录音。
- 一个声音档案可保存最多 5 段参考录音，并明确选中当前生成使用的样音；可随时添加、切换或删除备用录音，不需要建立多个同名声音。三款模型一次仍只接收一段当前样音，界面不虚假宣称多段联合克隆。
- 项目和任务超过首屏数量时提供“查看其余/收起”，不再静默截断旧项目与排队任务。
- 字幕配音、多人对话已提升为侧栏主创作入口；“本地引擎”单列为模型管理，许可证统一使用可阅读的弹窗。
- 未填写项目名称时，项目、队列任务和生成记录会取文稿开头 12 个有效字自动命名。
- 已创建的声音可以直接重命名，不需要删除后重新克隆。
- “我的声音”卡片可直接播放或暂停当前选中的参考录音；真实声音档案通过受控本地音频协议读取样音，渲染层不接触录音文件路径。
- 设置页已加入手动检查更新：Main 读取 GitHub 最新正式 Release，显示版本差异并打开固定下载页，不静默覆盖便携程序。
- 仓库 README 已按下载、能力、上手、模型、硬件、文件、更新、隐私、开发和许可顺序重写；声作本体采用源码可见、保留全部权利的专有许可，第三方许可继续单独保留。
- 含模型包已删除用途重复的“安装到本机模型库.cmd”，需要固定模型位置时统一通过设置页“迁移位置”完成。
- 正式模型收敛为 VoxCPM2、Fun-CosyVoice3 与 IndexTTS-2.5；旧插件、旧 Worker 与旧安装分支已从仓库删除。
- VoxCPM2 标为 5.0 星“综合最推荐”，负责真实克隆、自由表达、声音设计、30 种语言与 9 种中文方言。
- Fun-CosyVoice3 标为 4.5 星“方言更多”，完整列出并提供 19 种中文方言/口音选择。
- 语言/方言菜单显示完整选项；当前模型不支持的项目带锁，悬停提示需要切换的模型。
- VoxCPM2 已接入固定官方 revision、完整 SHA-256 清单、隔离 Python/CUDA 运行时、一键下载与环回 Worker；从最终完整便携包直接读取模型并使用 CUDA 生成 8.48 秒 MP3 成功。
- CosyVoice 方言选择已接入 `inference_instruct2`，普通克隆根据是否提供录音原文选择零样本或跨语言推理；从最终完整便携包直接读取模型并使用 CUDA 生成 5.84 秒 MP3 成功。
- IndexTTS-2.5 已接入固定官方 revision、主权重与四组离线辅助权重 SHA-256、独立 Python 3.10/CUDA 12.8 运行时、五种语言、8 维情绪控制和文本情绪引导；从最终完整便携包直接读取模型并使用 CUDA 生成 5.584 秒 MP3 成功。
- 三个模型集中保存在独立模型库，默认位置为 `%LOCALAPPDATA%\声作模型库`；下载前可选位置，设置中可整体迁移，应用内可一键打开，退出后可直接删除目录；旧版目录会自动迁移，不重新下载。
- 启动时真实检测 NVIDIA 型号、驱动、显存和系统内存；显存满足模型要求时自动使用 CUDA，否则自动切换 CPU，低于 16GB 内存时给出明确提示。Python、FFmpeg、PyTorch 与模型依赖均在各模型隔离运行时内自动准备。

- “批量字幕”已重构为用途明确的“字幕配音”：SRT 按字幕块解析并显示原时间码，TXT 按标点和换行拆句；支持逐句修改、删除、统一声音与停顿，最后合并为一个 MP3。

- 开发目录中的 `启动.cmd` 会比较构建时间，源码刚更新时自动打开本次构建，避免审核时误开旧打包版；分享目录仍直接打开打包程序。
