# 开发进度

最后更新：2026-08-17（Asia/Shanghai）

## 当前产品状态

- 产品名、图标、设计、README、帮助、隐私和启动方式已统一为“声作 1.0.0”。
- 正式模型收敛为 VoxCPM2、Fun-CosyVoice3 与 IndexTTS-2.5；旧插件、旧 Worker 与旧安装分支已从仓库删除。
- VoxCPM2 标为 5.0 星“综合最推荐”，负责真实克隆、情绪、声音设计、30 种语言与 9 种中文方言。
- Fun-CosyVoice3 标为 4.5 星“方言更多”，完整列出并提供 19 种中文方言/口音选择。
- 语言/方言菜单显示完整选项；当前模型不支持的项目带锁，悬停提示需要切换的模型。
- VoxCPM2 已接入固定官方 revision、完整 SHA-256 清单、隔离 Python/CUDA 运行时、一键下载与环回 Worker；从最终完整便携包直接读取模型并使用 CUDA 生成 8.48 秒 MP3 成功。
- CosyVoice 方言选择已接入 `inference_instruct2`，普通克隆根据是否提供录音原文选择零样本或跨语言推理；从最终完整便携包直接读取模型并使用 CUDA 生成 5.84 秒 MP3 成功。
- IndexTTS-2.5 已接入固定官方 revision、主权重与四组离线辅助权重 SHA-256、独立 Python 3.10/CUDA 12.8 运行时、五种语言、8 维情绪控制和文本情绪引导；从最终完整便携包直接读取模型并使用 CUDA 生成 5.584 秒 MP3 成功。
- 三个模型集中保存在独立模型库，默认位置为 `%LOCALAPPDATA%\声作模型库`；下载前可选位置，设置中可整体迁移，应用内可一键打开，退出后可直接删除目录；旧版目录会自动迁移，不重新下载。
- 启动时真实检测 NVIDIA 型号、驱动、显存和系统内存；显存满足模型要求时自动使用 CUDA，否则自动切换 CPU，低于 16GB 内存时给出明确提示。Python、FFmpeg、PyTorch 与模型依赖均在各模型隔离运行时内自动准备。
- 单段配音、字幕配音、多人对话、生成记录与 MP3 导出共用三个模型；一次只加载一个大模型。
- “批量字幕”已重构为用途明确的“字幕配音”：SRT 按字幕块解析并显示原时间码，TXT 按标点和换行拆句；支持逐句修改、删除、统一声音与停顿，最后合并为一个 MP3。
- 分享包只保留 `启动.cmd` 一个入口。轻量 ZIP 不携带权重；含三模型完整便携版携带三套运行时、源码和权重，但不携带缓存、私人录音、生成结果或任务数据。
- 自用版已清理授权确认、隐私宣讲和重复说明；克隆流程只保留选择录音、命名和填写原文。
- 生成记录已改为按日期分组的紧凑音频列表；收藏状态持久保存，可筛选收藏，并可确认删除记录及 MP3 文件。
- P0 长任务断点续做与逐句缓存已完成：每个稳定句子 ID 单独保存指纹和 MP3，失败、取消、重启或修改单句后只生成缺失/变化片段。
- P1 持久任务队列已完成：多份配音可连续提交并按顺序后台执行，运行中任务重启后自动回到队列，可取消和失败重试。
- P1 完整项目已完成：保存稿件、分句、声音、模型、语言、情绪、语速、音量与停顿，并可从“项目与记录”继续编辑。
- 模型管理已增加磁盘预检、下载字节/速度/剩余时间、断点恢复、官方/备用源切换和离线目录导入；离线资产按安装收据重新做 SHA-256 校验后才替换。
- 模型下载与运行环境安装现在都可随时暂停；未完成文件使用稳定 `.part` 断点，下载状态原子写入模型目录。退出软件后断点保留，下次打开直接显示“继续”，已完成的缓存、源码包和权重不重复下载。
- 点击未安装模型时会先显示完整下载位置，可直接下载或选择其他磁盘。设置页可整体迁移已下载模型、独立运行时与未完成断点；迁移会检查目标冲突和磁盘空间，跨盘复制按相对路径与文件大小核对后才切换，新位置会持久保存并优先于便携包默认目录。
- 克隆录音已增加时长、音量和爆音检查，并按录音字数/时长提醒明显不匹配的原文。
- 克隆录音支持从资源管理器任意位置直接拖入，拖入和“选择音频”共用格式、100MB 大小上限、时长、音量、底噪与爆音检查。
- 设置页已增加一键脱敏诊断 ZIP，不包含稿件、录音、生成音频、访问令牌或完整私人路径。
- 创作页已压缩为 1280×720 一屏完整布局：项目名称是独立输入框，三步状态横向排列，试听、生成和正文输入无需滚动即可使用；其他长页面仍保留明显滚动条和“下方还有内容”提示。
- “模型与语言”已改为常驻双列面板，模型、语言、音量和格式无需展开且在 1280×720 下仍无纵向溢出。
- VoxCPM2 普通克隆不再把默认表达文字拼入正文；方言使用简短控制标签并自动切换到可控克隆，避免“请用某方言自然表达”被念出，同时避免续写克隆覆盖方言控制。普通话、粤语、东北话均已用 RTX 4070 从真实模型生成成功，另有 2 项提示词隔离测试防止回归。
- “项目与记录”已去除已完成任务与生成记录的重复展示；队列只显示等待、生成中或失败任务。项目横向排列，音频记录改为有最大宽度的紧凑卡片，播放进度与导出、收藏、删除操作收在同一行并继续按日期分组。
- 设置页已增加“一键检查修复”，真实检查本地后台、Worker 文件、环回端口、模型 Python/权重收据/FFmpeg、文件权限和硬件，并自动补齐缺少的基础目录。
- 设置页已删除“自动保存”“一次加载一个模型”“文件校验”“输出格式”等纯说明项，只保留检查修复、模型文件夹、运行设备、帮助、诊断包和开源许可。
- 自动化交互测试已覆盖字幕导入、逐句编辑/删除、保存、提交生成、停止、重启恢复数据、导出、下载/安装暂停与继续、录音拖入。
- 导出命名已统一：默认使用“项目名称*日期*时间”，设置中可组合项目、日期、时间、类型和模型并实时预览；规则与上次导出文件夹跨启动保留，Windows 保存窗口仍可临时改名。
