# 声作 1.0.1

发布日期：2026-10-26。

## 本次改进

- **长稿稳定性**：使用早期合格的完整音频／原文作为固定参考，减少逐段递归传递带来的声线漂移；非默认语速先还原再作为模型参考。重做参考后，相关片段和缓存同步更新。
- **生成与恢复**：修复逐句停顿未应用、合并时长不准确、五分钟连接提前超时、停止后工具进程残留，以及超过 100 条任务时旧记录被截断的问题。
- **编辑与试听**：长稿、多人对话支持连续撤销删除；试听互斥播放；修复长录音定位、切换结果状态和播放失败提示，历史录音也显示质量提醒。
- **运行环境**：Electron 更新为 44.7.0，路由与文稿解压组件同步更新；版本号、Windows 构建与便携包文件名统一为 1.0.1。

## 验证范围

- 格式、Lint、严格类型检查、163 项 TypeScript 测试和 2 项 Excel 测试夹具测试通过。
- 32 项 VoxCPM2 Worker 测试、环回地址／一次性令牌检查和音频资源检查通过。
- 生产构建、Windows 打包、38 张常规截图、1 张 150% 缩放截图和隐藏窗口交互测试通过。
- 本机 RTX 4070、VoxCPM2、1.5 倍语速：原问题稿件 3 段、34.579 秒；完整 Excel 旁白 54 条、2,324 个非空白字符，成品 309.098 秒，54 段检查通过（5 段自动重做后通过）。同时验证排队取消、缓存重放、生产音频协议和播放定位。旁白按完整单元格读取，包含换行后的正文。
- 便携 ZIP 的 141 个应用文件逐项核对 SHA-256，确认应用 1.0.1、Electron 44.7.0，与最终构建一致；生产依赖审计没有已知漏洞。

声学检查不能证明逐字准确或保证模型永不重复、漏读、变调。正式作品仍需试听；本轮没有把不准确的听写结果设为自动无限重试的门槛。

## 获取与更新

下载 `ShengZuo-1.0.1-Windows-Portable.zip` 及同名 `.sha256.txt`，完整解压到新文件夹，运行其中的 `启动.cmd`。请先手动退出正在运行的旧版本，避免旧窗口仍显示旧代码；不要覆盖正在运行的旧程序目录。

便携包不包含模型权重、私人声音、项目或测试生成音频。现有本机数据继续保存在原位置；模型库保持按需下载／离线导入。
