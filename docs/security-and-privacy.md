# 安全与隐私

## 1. 数据原则

- 默认本地处理，不上传文本、音频、音色或项目。
- 本轮不包含遥测、账号或云端服务。
- 收集最少诊断信息；导出前由用户主动触发。
- 日志不记录完整配音文本、原始声音、密钥或完整私有路径。

## 2. 进程隔离

Renderer 使用 Chromium sandbox、context isolation 和禁用 Node integration。Preload 只暴露固定方法；主进程验证参数。三款模型 Worker 均作为低信任进程处理，限制监听地址、请求大小、环境变量、工作目录和可写范围；同一时间默认只加载一个模型。

## 3. IPC 风险控制

- channel 白名单。
- 输入长度、枚举、路径与 ID 的 TypeScript 类型及运行时双重验证。
- 文件选择由系统对话框产生，不信任 Renderer 提供的任意目标。
- 导出采用已知资源 ID，不允许 Renderer 传源文件路径。
- 导出文件名移除 Windows 非法字符并限制长度；真实结果通过不可枚举的资源 ID 解析到主进程已知 MP3。
- 取消、重试和状态变更验证当前状态，防止竞态。

## 4. 文件与下载

- 下载仅允许清单中 HTTPS 域名。
- 断点文件与最终文件分离。
- SHA-256 与清单自检通过后才可安装。
- 使用临时目录和原子重命名。
- 检查 ZIP Slip、符号链接和路径穿越。
- 磁盘空间不足时在下载前中止并给出中文指引。

## 5. Worker 网络

真实 Worker 只监听 `127.0.0.1` 随机端口。启动令牌完成一次握手后失效并换成会话令牌；同时校验远端地址、Host 和 Origin。Windows 防火墙不需要对外开放端口。任何尝试绑定 LAN/公网的插件都视为不兼容。

## 6. 日志脱敏

允许：版本、模型 ID、任务 ID、文本长度、硬件摘要、状态、耗时、内部错误码。  
禁止：全文、原音频、训练样本、访问令牌、用户名、完整项目路径、原始请求体。

## 7. 诊断包

诊断包未来包含应用版本、系统版本、脱敏硬件信息、模型清单、校验摘要、最近错误和日志。生成前显示内容说明；压缩包默认不含用户项目和音频。

## 8. 当前限制

已完成三款模型的本地 Worker、固定 revision 下载、关键文件与权重 SHA-256 校验、一次性启动令牌和会话令牌。仍未完成 Worker 的 Windows 低完整性令牌/AppContainer、插件代码签名、自动更新签名与多机型发布矩阵；这些不能被视为已通过。
