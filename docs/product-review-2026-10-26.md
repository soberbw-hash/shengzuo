# 声作：体验审查与迭代路线

审查日期：2026-10-26。对象是已有 Windows 本地版，不是重新设计品牌或创建新产品。

## 本轮结论

首先解决音频是否完整、稳定、可续做，其次减少编辑和试听误操作。保留蓝色／薄荷色、中文文案、三种创作结构、离线模型库和无账号设计。

## 实际流程与证据

初始首页通过实际应用窗口截图检查；其余界面使用当日独立隐藏窗口的真实渲染截图和交互测试，不占用用户前台。截图不包含用户私人稿件。自动测试状态和示例录音不能代替真实模型听感。

1. **选择声音和输入稿件：健康。** 三步骤清楚，长稿另有入口；禁用选项有能力说明。大窗口编辑区还有利用空间，可后续按窗口高度适度伸展，避免增加新的说明卡片。
   ![创作入口](review-2026-10-26/02b-generate-compact-1280x720@1x.png)
2. **导入并逐句编辑：本轮改进。** 原来删除立即生效，没有恢复入口。现增加连续“撤销删除”，保留原时间码／角色／位置，不覆盖其他句子的修改；导入其他稿件或切换项目后不串用旧删除记录。
   ![长稿编辑](review-2026-10-26/02-subtitles-1280x720@1x.png)
3. **生成与失败恢复：最高优先级。** 已修复固定参考、音频哈希缓存、回查后依赖更新、停顿、合并时长、超时和取消。质量检查不能证明逐字完整，正式文稿仍需试听。
   ![生成状态](review-2026-10-26/10-generating-1440x900@1x.png)
4. **试听、版本管理和导出：本轮改进。** 原先创作与记录页使用不同播放逻辑，可能叠音、漏报错误和键盘定位不一致。现共用播放逻辑，全应用只播放一条试听，历史录音也显示质量提醒。
   ![项目与录音](review-2026-10-26/05-projects-1280x720@1x.png)
5. **模型选择和维护：健康，但需更明确的实测依据。** 已有许可、硬件需求、暂停续传、迁移和诊断；下一步应将推荐星级与可复现的本机测试区分，而不是不断增加模型卡片。
   ![本地模型](review-2026-10-26/06a-models-compact-1280x720@1x.png)

## 建议优先级

| 优先级   | 改进                                 | 验收标准                                                                                       |
| -------- | ------------------------------------ | ---------------------------------------------------------------------------------------------- |
| P0，本次 | 修复音频生成、续做与试听链路         | 原问题稿件、完整长稿、缓存重放、非默认语速、取消和播放定位均有验证；不把仅声学检查说成逐字正确 |
| P0，本次 | 新便携包确实更新                     | 程序、界面、构建配置、压缩包文件名版本一致；独立 SHA-256；GitHub 新版本链接明确                |
| P1，本次 | 删除可恢复、试听不叠音、质量提醒一致 | 真实点击测试覆盖撤销不覆盖编辑、两个播放器互斥、播放失败和键盘操作                             |
| P1，后续 | 可疑句定位与“只重做这一句”           | 同一文稿只更新指定句子的生成标识；其他合格音频按哈希复用；重新合并时停顿不丢失                 |
| P1，后续 | 本地内容复核                         | 听写和原文对齐，给出疑似重复／漏读的时间点；允许用户忽略；不把不准确的 ASR 变成无限重试门槛    |
| P1，后续 | 新旧版本 A/B 对听                    | 同一段落切换听，不能同时播放；显示模型、参考样音和生成参数，便于决定保留哪个版本               |
| P2，后续 | 批量导出与字幕伴随导出               | 目录选择、重名处理、进度、部分失败恢复；SRT 时间轴以真实生成时长为准                           |
| P2，后续 | 更自然的长稿工作区                   | 大窗口增大编辑区域；可搜索句子／标记需复听段落；小窗口仍保留主要按钮                           |
| P2，后续 | 常用设置组合                         | 保存模型、声音、语速、停顿和词典组合；明确项目设置与全局设置的边界                             |

## 无障碍与验证限制

下一轮应优先补上 Excel 旁白列选择：当前导入保留整张表的文本，用户需要确认哪些内容属于真正旁白，而不是直接朗读镜号和制作说明。测试夹具本轮改为按完整单元格读取，保留换行后的正文并校验原表有效字数，不能用固定行数代替内容完整性检查。

已经检查 1280×720 核心流程、150% 缩放、文字裁切、主要按钮位置和若干键盘操作。截图不能证明完整 WCAG 合规，也没有替代屏幕阅读器和真实长时间使用测试。本轮后续验证全用隐藏窗口且静音，不自动操作用户正在使用的软件。

## 发布后的取舍

不在维护版本中强制更换声音模型、搬迁私人数据或加入云端音频上传。按用户个人私用场景，不把商用许可作为选型门槛；新模型和校对器仍应隔离运行环境、保留上游说明、验证校验和、离线运行和同稿对照结果，再决定是否接入默认流程。
