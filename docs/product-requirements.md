# 产品需求文档

## 1. 产品目标

声作面向不熟悉模型部署的普通创作者。用户应当只通过 Windows 图形界面完成声音克隆、文字输入、试听、生成、导出和记录查看，不需要理解 Python、CUDA、命令行或环境变量。

产品身份：

- 正式名称：声作。
- 产品定位：本地声音创作工作台。
- 品牌主张：让自己的声音，成为作品。
- 命名边界：品牌不使用“克隆”作为主名称，避免把后续字幕、对话与声音创作能力限制在单一技术动作中。

核心承诺：

- 多模型：按任务选择最合适的本地模型。
- 本地优先：文本、声音和项目默认留在用户电脑。
- 一键安装：应用、模型插件和运行环境各自可管理。
- 可恢复：下载、生成和项目状态在异常后可解释、可重试。
- 易理解：用户看到创作语言，不看到 Python 堆栈或 CUDA 错误码。

## 2. 目标用户与场景

| 用户          | 主要任务             | 成功标准                                         |
| ------------- | -------------------- | ------------------------------------------------ |
| 短视频创作者  | 为口播、解说快速配音 | 选音色、粘贴文本、试听、导出不超过一个主流程     |
| AI 短剧创作者 | 多角色台词与逐句重做 | 自动识别角色，独立音色与表演，局部重做不破坏整段 |
| 长稿配音用户  | SRT/TXT 逐句生成音轨 | 自动分句、统一声音并自动拼接                     |
| 播客创作者    | 多人对话和旁白       | 多角色参数可独立设置并整段预览                   |

## 3. 计划模型

前端必须使用完整名称和用途标签：

| 模型                     | 突出特点                     | 推荐说明                     | 当前阶段                   |
| ------------------------ | ---------------------------- | ---------------------------- | -------------------------- |
| VoxCPM2                  | 真实克隆、自由表达与声音设计 | 综合最推荐，适合大多数创作   | 已接入，一键安装与真实生成 |
| Fun-CosyVoice3 0.5B 2512 | 更多中文方言、口音控制       | 需要中文方言时选择           | 已接入，一键安装与真实生成 |
| IndexTTS-2.5             | 情绪演绎、五种语言与发音控制 | 需要细腻语气和指定发音时选择 | 已接入，一键安装与真实生成 |

三个模型均使用隔离运行环境、固定来源版本、安装收据与 SHA-256 校验。界面只提供“下载并安装”“加载使用”等普通操作，不要求用户接触 Python、FFmpeg 或命令行。

## 4. 功能范围

### 4.1 配音生成

模型与运行状态、音色、文本、模型实际支持的表达或情绪控制、语言、语速、音量、格式、前 30 个有效字试听、开始/停止、进度、播放器、重新生成、导出和打开位置。VoxCPM2 显示表达要求；CosyVoice 仅在方言模式显示表达要求；IndexTTS-2.5 显示情绪与表达要求，填写具体表达时以表达要求优先。表达要求默认使用少量高频预设，选择“自定义”后才展开输入框。点击试听时要在正文框选中试听范围，并在按钮附近显示实际送入模型的文字；试听结果不进入生成记录，也不提供导出。

### 4.2 字幕配音

面向已有字幕稿或长文，不提供语音识别。导入 SRT 时按字幕块拆分并显示原时间码作为检查参考；导入 TXT 或粘贴文字时按标点和换行拆分。每句可独立修改、删除，最多 200 句；全部句子使用统一模型、声音、语言、该模型实际支持的表达控制、语速、音量和句间停顿，最终只保留一个完整 MP3。正式生成前可先试听开头 30 个有效字，界面明确显示试听内容，试听结果不进入记录。开始创作用于单段快速配音，字幕配音用于同声音整稿，多人对话用于多角色多声音。

### 4.3 多人对话

提供两种明确分开的导入方式。“直接识别”完全在本机运行，只拆分已经写成“角色名：台词”的规整脚本；“智能整理脚本”使用用户自己配置的文本 API，从小说、分镜稿或混杂脚本中删除场景、镜头、动作、表情、音效和普通叙事，只保留说话人明确的台词及原文明示的旁白或画外音。智能整理结果必须先展示识别出的角色、台词和实际删除的内容类别，用户确认后才替换编辑区。

智能整理使用仓库内可直接阅读和复用的 `prompts/多人对话脚本整理.md`，不绑定特定 API 提供方。提示词要求把用户原文当作数据，禁止续写、润色、翻译或猜测说话人；最多返回 200 句。整理完成后，角色名和台词仍可自由编辑，不限制为预设四个角色。一个项目统一使用同一模型和语言，避免同时加载多个大型模型；每个角色可独立选择音色与语速，只有模型真实支持独立情绪时才显示角色情绪。支持旁白、前 30 个有效字试听、逐句重做和整段导出，角色名称不得作为模型的表达提示词发送。

### 4.4 音色库

点击选择或从资源管理器直接拖入录音，填写录音原文，创建声音档案并删除不用的声音。两种导入方式共用格式、大小、时长、音量、噪声和爆音检查；创建前可以直接播放刚选中的录音，确认没有选错文件。当前版本不提供虚构内置人声、云端训练、声音市场或收藏功能。

### 4.5 项目

汇总三个模型跨次启动保留的真实生成结果，按日期紧凑分组，支持试听、收藏筛选、另存为 MP3 和删除记录及音频文件。导出文件名按用户保存的统一规则生成，可组合项目、日期、时间、类型和模型；保存窗口显示最终名称并允许临时修改，同时记住上次规则和导出文件夹。当前版本不提供团队协作或云端同步。

### 4.6 模型管理

名称、用途、版本、安装/下载状态、预计空间、推荐硬件与适配结论，以及一键安装、暂停续传、失败重试、加载使用、打开模型文件夹和许可查看。首次下载前可选择模型库位置；已安装模型可在设置中整体迁移，迁移后不需要重新下载。用户退出应用后可以直接删除单个模型文件夹；应用重新获得焦点时会刷新状态。

### 4.7 设置

只保留模型文件夹的打开与迁移、导出文件名规则、API配置、检查修复、检查更新、诊断包导出和许可入口，不展示不可操作的技术状态或重复说明。API配置只填写 Base URL、Model 和 API Key，保存即启用，新 Key 直接覆盖旧 Key。检查更新读取 GitHub 最新正式 Release，只提示并打开下载页，不静默覆盖便携程序。

### 4.8 智能文稿（可选）

用户可配置自己的 OpenAI 兼容文本接口，用于自然口语、整理停顿、精简文稿、检查发音、翻译和自定义处理。默认处理当前选中文字，没有选区时才处理全文；结果必须先展示原稿与修改稿对比，经用户确认后替换，并提供一次撤销。检查发音返回的建议可以加入项目发音词典；表达与情绪建议必须按当前 TTS 模型和语言的真实能力过滤，不向不支持的模型显示或发送无效控制。

此功能不配置也不影响本地克隆和配音。API Key 只允许在 Main 进程使用 Windows 安全存储加密，Renderer 不得读取明文。只在用户主动点击处理时发送当前选中的文稿、处理方式及模型能力标识，不发送录音、声音档案、生成音频、项目文件或本地路径。Base URL 默认要求 HTTPS，只允许回环地址使用 HTTP。

## 5. 非功能需求

- Windows 10/11 x64；1280×720 起可用，支持 150% 缩放。
- 支持中文用户名、中文路径、深层路径和非 C 盘模型目录。
- 无管理员权限也能完成正常配音。
- 下载失败可重试；固定版本文件完成 SHA-256 校验后才进入可用状态。
- 主应用与模型安装故障隔离。
- 所有用户错误为自然中文；技术详情进入脱敏日志。
- 默认同时仅加载一个大型模型，可按空闲时间释放显存。
- 智能文稿接口失败或未配置时，本地配音、项目保存和导出仍可独立使用。

## 6. 本轮验收范围

本轮验收 Phase 0、Phase 1 基础与 Phase 2 双模型精选本地闭环：

- 七页完整基础界面与共享组件，不保留独立帮助占位页。
- Mock Engine 的 11 个自动化状态与真实 LocalVoiceEngine 状态映射。
- 随项目生成的 2 秒离线 MP3 测试提示音，仅用于自动化状态。
- 三款模型的一键安装、录音克隆、CUDA/CPU 自动判断、MP3 播放与导出。
- 字幕配音、多角色对话、音频合并和跨会话生成记录。
- 统一模型文件夹、应用内一键打开、手动删除识别和 CMD 启动。
- 安全 Electron 壳与严格类型化 IPC。
- 格式、Lint、类型、自动化测试、Windows unpacked 开发构建和截图证据。

暂不验收正式代码签名、自动更新、Windows AppContainer 或完整多硬件发布矩阵。
